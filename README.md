# Stock Market ML: Units 1–4

A compact teaching project that demonstrates the complete Unit 1–4 syllabus using daily data for AAPL, MSFT, GOOGL, AMZN, and NVDA.

## Run it

From this folder, activate the project environment and install the packages:

```powershell
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

If PowerShell activation is unavailable, use the environment's Python directly:

```powershell
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe main.py
```

The default command reuses the saved CSVs in `data/processed/` and runs all four units. It does not download again when those files are available.

```powershell
python main.py --unit 1       # Unit 1 only
python main.py --unit 2       # Unit 2 only
python main.py --unit 3       # Unit 3 only
python main.py --unit 4       # Unit 4 only
python main.py --refresh      # download the 2015–2025 data again, then run all four
```

If the processed files are missing, the program builds them from `data/raw/`; if raw files are also missing, it downloads them. A network connection is needed only for a download.

## Project files

- `main.py` — data preparation and the only command-line entry point.
- `unit1.py` — Unit 1 lessons.
- `unit2.py` — Unit 2 lessons.
- `unit3.py` — Unit 3 lessons.
- `unit4.py` — Unit 4 lessons.
- `data/raw/` — downloaded daily stock data.
- `data/processed/` — cleaned data with features and next-day targets.
- `results/` — simple plots generated by the lessons.

## Unit 1 — Introduction and probability

| Topic | What the lesson demonstrates |
|---|---|
| What and why machine learning | Learns patterns from examples to predict or group observations. |
| Supervised and unsupervised learning | Predict next-day targets versus grouping days with K-means without labels. |
| Polynomial curve fitting | Fits low- and high-degree curves; compares training and test error to explain underfitting and overfitting. |
| Discrete random variables and fundamental rules | Up/down and RSI categories; joint probabilities, sum rule, and product rule. |
| Bayes' rule | Calculates the probability of an RSI regime given an up-day target. |
| Independence and conditional independence | Chi-square tests overall and within high/low volatility groups. |
| Continuous random variables and probability densities | Models AAPL daily return values and plots a fitted Student-t density. |
| Quantiles, mean, variance, expectation | Summarizes returns, spread, expected return, and tail cutoffs. |
| Covariance | Calculates how the five stocks' returns vary together and the volatility of an equal-weight portfolio. |

## Unit 2 — Linear models

| Topic | What the lesson demonstrates |
|---|---|
| Maximum likelihood and least squares | Explains why Gaussian-error maximum likelihood gives the least-squares solution. |
| Robust linear regression | Uses Huber regression to reduce sensitivity to large errors. |
| Ridge regression | Shrinks coefficients and selects penalty strength on validation dates. |
| Bayesian linear regression | Predicts a return and reports uncertainty intervals. |
| Discriminant function and generative models | LDA models feature patterns within each class and applies Bayes' rule. |
| Discriminative models | Logistic regression directly estimates the probability of an up day. |
| Laplace approximation and Bayesian logistic regression | Approximates uncertainty around logistic-regression weights and adjusts probabilities. |
| Kernel functions and kernel trick | Confirms a polynomial kernel matches an explicit feature expansion. |
| Kernels in GLMs | Feeds RBF-kernel similarities into logistic regression (kernel logistic regression; fit uses a 1,000-row sample for speed). |
| SVMs | Compares linear and RBF support vector classifiers. |

The kernel lesson compares the explicit polynomial expansion with the polynomial kernel function. Both give the same similarities; the kernel computes them without building the expanded feature matrix. It also uses kernel similarities in logistic regression and kernel ridge regression. Kernel regression fits 1,200 training rows and SVMs fit 1,500 training rows for speed; each is evaluated on the full later test split.

## Unit 3 — Mixture models and clustering

| Topic | What the lesson demonstrates |
|---|---|
| K-means | Hard assignment of observations to clusters by distance to cluster centers. |
| Gaussian mixtures and EM | Soft cluster probabilities, EM updates, model likelihood, and BIC-based component selection. |
| Alternative view of EM | Responsibilities act as fractional membership weights for observations. |
| Factor analysis and PCA | Two latent-variable views of the six stock indicators. |
| Choosing latent dimensions | PCA explained-variance thresholds and factor-analysis validation likelihood. |
| Dissimilarity and clustering evaluation | Euclidean/cosine distances, silhouette, Davies-Bouldin, and exploratory adjusted Rand score. |
| Hierarchical clustering | Ward linkage, agglomerative labels, and a dendrogram. |

## Unit 4 — Hidden Markov models

| Topic | What the lesson demonstrates |
|---|---|
| Sequential data and Markov models | Daily AAPL returns are ordered and discretized; an empirical first-order Markov model predicts the next return category. |
| HMM and maximum likelihood | A two-state hidden regime model is fit by Baum-Welch, the EM maximum-likelihood procedure. |
| Forward and backward algorithms | Scaled sum-product message passing computes the observation-sequence likelihood and hidden-state posteriors. |
| Scaling factors | Forward normalization factors keep long-sequence probabilities numerically stable. |
| Viterbi algorithm | Max-product dynamic programming decodes the most likely hidden-state sequence. |
| Linear dynamical systems | A scalar linear-Gaussian state-space model is filtered with a Kalman filter. |

Unit 3 outputs PCA/clustering plots. Unit 4 outputs a hidden-regime and Kalman-filter plot. HMM states are learned latent regimes and do not have an intrinsic up/down meaning; labels can swap without changing the model.

## Data and evaluation

Features are calculated from information available on or before each date. Targets are the following trading day's adjusted-price return and its direction. Predictive models use a chronological split: training through 2021, validation in 2022–2023, and testing after 2023. Scaling is fitted on training data only. The clustering and HMM lessons use sequential or unsupervised analysis and state their own sampling and evaluation choices.

Regression reports RMSE and R-squared. Classification reports accuracy, precision, recall, ROC-AUC, and a confusion matrix. Results are demonstrations on five large technology companies; they should not be generalized to the whole market.
